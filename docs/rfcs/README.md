# RFCs

An RFC proposes a change and records why. Each one says its status right under its title:

| Status | Meaning |
| --- | --- |
| **Draft** | Open for discussion. Nothing in it is decided, even if it's merged. |
| **Accepted** | Decided. It may not be built yet. |
| **Withdrawn** | Not going ahead. Kept for the reasoning. |

A merged RFC can still be a draft: drafts are merged so they can be read, linked and changed
in later PRs. Only a maintainer changes a status, in a PR that says so.
